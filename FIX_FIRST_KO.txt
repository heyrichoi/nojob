=== v5.1 먼저 할 것 ===

1) 기존 프로젝트의 .env는 그대로 보관하세요.
   - v5.1 압축에는 보안을 위해 실제 .env를 넣지 않았습니다.
   - 기존 .env를 v5.1 폴더 루트로 복사하세요.

2) Google Apps Script 수정
   - 기존 Apps Script의 Code.gs 내용을 전부 삭제
   - 이 압축의 google_apps_script/Code.gs 전체를 붙여넣기
   - 함수 선택 -> setup -> 실행 -> 권한 승인
   - 배포 -> 배포 관리 -> 기존 웹앱 연필(수정)
   - 버전 -> 새 버전
   - 액세스 권한 -> 모든 사용자
   - 배포
   - 나온 /exec 주소를 브라우저에서 직접 열었을 때 {"ok":true,...} JSON이 보여야 정상
   - 새 URL이면 .env의 SHEET_WEBAPP_URL도 교체
   - 서버 재시작

3) Windows 실행
   - start_windows.bat 실행
   - 또는 PowerShell에서 npm.cmd start

4) TTS 테스트
   - http://localhost:3000/overlay?debug=1 을 먼저 열기
   - 일반 Chrome 테스트라면 우하단 '브라우저 오디오 활성화' 클릭
   - http://localhost:3000/control 에서 TTS 테스트
   - 실패하면 컨트롤 화면에 실제 Typecast HTTP 오류가 표시됩니다.
   - OBS에서는 브라우저 소스에 /overlay를 넣고 'OBS를 통해 오디오 제어'를 켜세요.

5) 외부 공유
   - localhost는 다른 사람이 열 수 없습니다.
   - 테스트: cloudflared tunnel --url http://localhost:3000
   - 표시된 https://xxxx.trycloudflare.com/overlay 를 8명 모두에게 동일하게 전달
   - Quick Tunnel은 테스트용이며 재실행 시 주소가 바뀔 수 있습니다.
